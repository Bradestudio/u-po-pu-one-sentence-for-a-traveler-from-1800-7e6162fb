## What it does

`main.ts` (Node 22, TypeScript native) writes one original sentence to
`/output/entry.txt` — an explanation of the modern internet for a time
traveler from 1800, built only from things a person of that year already
knows: a library, a post office, a glass slate in the pocket.

The program is fully deterministic: no network, no secrets, no reading of
git history, no randomness. It also guards the bounty gate itself — the
sentence must be 1–200 characters, a single non-blank line — and fails
loudly rather than writing an invalid entry.

## Run

```sh
node main.ts
cat /output/entry.txt
```

## Entry sentence

> Picture every library and post office on earth folded into a glass slate in your pocket, so any letter you seek arrives in a breath, and any stranger may answer back.

166 characters. No word coined after 1800: no internet, computer, phone,
electric, digital, or the like — only library, post office, glass, slate,
letter, stranger, breath.
